Production Deployment Guide  |  Database: Supabase (PostgreSQL)  |  Frontend: Cloudflare Workers  |  Backend: Render PaaS

1. Overview & Architecture

This software is a full-stack employee onboarding portal designed for an HR admin to invite new hires and collect identity documents safely. To deploy it to real users:

  • Database & Storage: Supabase provides managed PostgreSQL for records and private S3-compatible Object Storage for sensitive employee documents.
  • Backend API: Node.js + Express + Prisma deployed on a platform like Render or Railway.
  • Frontend & Proxy: React + Vite deployed on Cloudflare Workers, which acts as a reverse proxy forwarding /api/* requests directly to your backend service without CORS complications.
  • Custom Domain: onboarding.infiniticodetech.com connected via Wix DNS CNAME.

2. Step-by-Step Setup

Step 1: Set Up Supabase Database & Storage

  1. Log in to supabase.com and click New Project. Name it infiniti-onboarding.
  2. Set a secure database password (≥ 12 chars). Choose a region closest to your users.
  3. Go to Settings → Database → Connection Pooling and copy the PostgreSQL URI: 
    postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres?sslmode=require
  4. Go to Storage → Buckets → New bucket:
    • Bucket name: onboarding-docs
    • Public bucket: Disabled (Keep private for compliance)
  5. Go to Project Settings → API and copy your Project URL and service_role secret key.

Step 4: Connect Cloudflare Worker & Deploy Frontend

Update worker/index.js so it proxies incoming /api/* requests directly to your Render backend:

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    if (url.pathname.startsWith("/api/")) {
      const backendOrigin = env.BACKEND_URL || "https://infiniti-backend.onrender.com";
      const targetUrl = new URL(url.pathname + url.search, backendOrigin);
      const headers = new Headers(request.headers);
      headers.set("Host", new URL(backendOrigin).host);
      headers.set("X-Forwarded-Host", url.host);
      headers.set("X-Forwarded-Proto", "https");

      return fetch(new Request(targetUrl, {
        method: request.method,
        headers: headers,
        body: ["GET", "HEAD"].includes(request.method) ? null : request.body,
        redirect: "manual"
      }));
    }
    return env.ASSETS.fetch(request);
  }
};

In wrangler.jsonc, add your backend URL:

{
  "name": "infiniti-onboarding-portal",
  "main": "worker/index.js",
  "compatibility_date": "2026-11-11",
  "assets": {
    "directory": "./client/dist",
    "binding": "ASSETS",
    "not_found_handling": "single-page-application",
    "run_worker_first": ["/api/*"]
  },
  "vars": {
    "BACKEND_URL": "https://infiniti-backend.onrender.com"
  }
}

Build and deploy to Cloudflare:

# Login to Cloudflare
npx wrangler login

# Build Vite client assets
npm run build

# Deploy Cloudflare Worker
npm run deploy

Step 5: Connect Custom Domain on Wix DNS

  1. In the Cloudflare Dashboard → Workers & Pages → infiniti-onboarding-portal → Settings → Domains & Routes → Add Custom Domain: enter onboarding.infiniticodetech.com.
  2. Log in to your Wix Domain Manager → Select infiniticodetech.com → Manage DNS Records.
  3. Add a new CNAME Record:
    • Host Name: onboarding
    • Points To: The CNAME target indicated by Cloudflare (e.g. infiniti-onboarding-portal.[subdomain].workers.dev)
    • TTL: 1 Hour (or Automatic)
Important: Do NOT modify existing @ (A record), www, or MX mail records on Wix. Those power your primary website and company email.
